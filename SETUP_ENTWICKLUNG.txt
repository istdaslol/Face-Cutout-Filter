Entwicklungsumgebung einrichten (Windows, PowerShell)

1. Python 3.11 (64 Bit) installieren (python.org). NICHT 3.12 oder neuer.
2. Im Projektordner:

     py -3.11 -m venv .venv
     .\.venv\Scripts\Activate.ps1
     python -m pip install --upgrade pip
     pip install -r requirements-dev.txt
     python tools\fetch_model.py

3. Pruefen:

     python -c "import mediapipe, cv2, numpy, PySide6, pyvirtualcam; print(mediapipe.__version__, cv2.__version__, numpy.__version__)"
   Erwartet: 0.10.21 4.11.0 1.26.4

Falls Skripte in PowerShell blockiert sind:
     Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

4. Tests:
     pytest -q
   (Tests mit echtem Modell brauchen Bilder in tests\bilder\, sonst werden sie uebersprungen.)

5. Programm starten:
     python run.py
   Log-Datei bei Problemen:  %APPDATA%\Gesichtsfilter\log.txt
   Zuletzt benutzte Einstellungen:  %APPDATA%\Gesichtsfilter\zuletzt.json
   (zum Zuruecksetzen diese Datei loeschen)

Linux (Ubuntu, apt)
-------------------
   chmod +x install.sh        (falls das Ausfuehrungsrecht fehlt; alternativ: bash install.sh)
   ./install.sh --dry-run     zeigt nur, was passieren wuerde
   ./install.sh               installiert Systempakete, Python (3.10-3.12), .venv, Pakete, Modell,
                              virtuelle Kamera (v4l2loopback, /dev/video10 "Gesichtsfilter") und Startbefehl
   gesichtsfilter             startet das Programm
   ./install.sh --uninstall   entfernt Startbefehl, Menueeintrag, .venv und Kamera-Einstellungen
   Weitere Optionen: ./install.sh --help
   Hinweis: Bei aktivem Secure Boot muss das v4l2loopback-Modul signiert sein (siehe Meldung des Skripts).

Foto-Ordner:  <Bilder>/Gesichtsfilter   (im Programm mit "Ordner ..." aenderbar)

WSL2 und Windows im selben Ordner
---------------------------------
   Eine Windows-.venv (Scripts\python.exe) und eine Linux-.venv (bin/python) sind verschieden aufgebaut und
   koennen nicht gemeinsam in einem Ordner liegen. install.sh erkennt das bewusst nicht und fasst eine
   vorhandene fremde .venv nicht an; der Lauf bricht dann mit
   ".venv/bin/python: No such file or directory" ab.
   Abhilfe: Projekt fuer WSL ins Linux-Home kopieren (z.B. ~/Face-Cutout-Filter) und dort installieren,
   oder die Windows-.venv umbenennen. Unter WSL2 gibt es ausserdem keine Webcam (ohne usbipd-win) und keine
   virtuelle Kamera; die Windows-Version ist fuer den Betrieb gedacht.
